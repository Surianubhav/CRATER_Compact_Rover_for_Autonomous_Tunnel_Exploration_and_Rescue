# MineRover SLAM

This repository contains the SLAM (Simultaneous Localization and Mapping) implementation and related utilities for the MineRover project. It interfaces with an ESP32 controlling a TF-Luna LiDAR, AS5600 encoders, and an MPU6500 IMU over UDP to generate live 2D maps.

## Project Structure

- `src/`: Core mapping and SLAM scripts.
  - `slam.py`: Main SLAM entry point utilizing LiDAR, IMU, and encoder data to generate a map.
  - `mapping2d.py`: Core 2D map generation algorithms.
- `calibration/`: Scripts for calibrating rover hardware.
  - `calibrate_imu.py`: IMU calibration tool.
  - `calibrate_motor.py`: Motor and drive calibration.
  - `calibrate_trackwidth.py`: Track width calibration for accurate turn estimations.
- `lidar_tools/`: Specific tools and tests for the LiDAR sensor.
  - `lidar_map.py`: Standalone LiDAR map visualization.
  - `lidar_occupancy.py`: Occupancy grid generation from LiDAR data.
  - `lidar_receiver.py`: Basic UDP receiver for LiDAR data.
- `utils/`: Helpful utilities for debugging and network communication.
  - `udp_receiver.py`: General UDP data receiver for telemetry.
  - `monitor_encoders.py`: Debug script to monitor live encoder values.
- `data/`: Sample outputs and generated maps.
  - `example_map.png` / `example_map.npz`: Example of an optimized map generated by the rover.

## Setup

1. Install the required Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Ensure your computer is connected to the same network as the rover's ESP32, which should be broadcasting telemetry over UDP to ports 4211 (LiDAR) and 4212 (Odometry).

## Usage

To launch the real-time mapping visualization, run:
```bash
python src/slam.py
```
